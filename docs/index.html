Which model should answer each math question?

EnergyAware AI replays 400 GSM8K questions that were run through three Qwen2.5 models while a GPU power meter was logging. Move the slider to trade accuracy for energy.

Result in one line: the learned router did not beat a simple fixed policy. At 95% of the large model’s accuracy it saved 6.8% energy against 7.2% for the best fixed mix (difference −0.4 points, 95% interval −4.9 to +4.7).

At 0 the router always picks the model most likely to be right. Higher values favour cheaper models.

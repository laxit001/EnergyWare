# Data

- `demo_data.json` - the 400 GSM8K questions with per-tier correctness, energy and router predictions used by the demo.

Copy these files from your `MyDrive/energyaware` folder after running the notebooks (they are small):

- `queries.jsonl` - the 800 queries and gold answers
- `results.jsonl` - 2,400 records (query x tier): correctness, latency, raw and net GPU energy, token counts
- `pareto_curve.png` - quality-versus-energy plot from notebook 02

`probe_feats.npz` (hidden-state features, a few MB) is regenerated by notebook 03 and is not committed.
